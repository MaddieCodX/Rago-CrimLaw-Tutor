Put Professor Rago's Criminal Law slide decks (.pptx) in this folder, one file per topic.

The file name is what students see in the topic menu, so name them clearly, for example:
  Week 01 - Elements of a Crime.pptx
  Week 02 - Homicide.pptx

After uploading a new deck to GitHub, wait a minute and refresh the app; the new topic
appears on its own. If it doesn't, use Manage app -> Reboot app.

This README file is ignored by the tutor. It only keeps the folder in place on GitHub.
